Welcome To Your Local Automatic Rainbow Analyzing Software!

To get set up, please follow the instruction down below depending on your Raspberry Pi's abilities

Option 1: You are able to run a browser well on your Raspberry Pi

You have over 1GB of RAM installed
  1. Set up you Raspberry Pi and download the OS
  2. Follow SetUp instructions
  3. Now navigate to this home page on your Raspberry Pi and click here to download the zip file needed
  4. Now upzip the file and put it in the folder right underneath the folder with your username
  5. Open up a terminal and type in "cd 'username'" where you put your Raspberry Pi username in the command
  6. Next type "dos2unix setup.sh" and click enter
  7. Lastly, run "./setup.sh"

    8. Option 2:

  8. Connect both your local machine and your Raspberry Pi to the same network
  9. Click here to download the zip file needed
  10. Now go to your Windows Command Terminal and input "scp /path/to/your/file.zip pi@:/path/to/destination"
